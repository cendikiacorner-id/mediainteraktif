⏳ Memeriksa...

🔗 Alamat Web App

Tempelkan URL Apps Script. Cukup sekali, akan tersimpan di perangkat ini.

📋 Cara Menyambungkan

Cukup dilakukan satu kali. Perlu waktu sekitar 10 menit.

Buat spreadsheet baru Buka sheets.new di tab baru, beri nama Dashboard Guru.
Buka Apps Script Pada spreadsheet, klik menu Extensions → Apps Script.
Tempel kode Hapus kode bawaan, lalu tempel seluruh isi berkas kode-apps-script-dashboard.txt. Simpan dengan Ctrl+S.
Terbitkan Web App Klik Deploy → New deployment → ikon roda gigi → pilih Web app.
Execute as: Me  ·  Who has access: Anyone
Izinkan akses Klik Deploy → Authorize access → pilih akun → Advanced → Go to project (unsafe) → Allow.
Salin URL Salin Web app URL yang muncul, lalu tempelkan pada kolom di atas dan klik Simpan URL.
https://script.google.com/macros/s/AKfycb....../exec
⚠️ Penting
Pada langkah 4, Who has access harus diatur ke Anyone. Jika tidak, pengiriman data akan gagal.
💡 Setelah tersambung
Spreadsheet akan berisi 4 lembar otomatis: Data Siswa, Rekap Absensi, Daftar Tugas, dan Rekap Nilai — lengkap dengan pewarnaan status.

❓ Pertanyaan Umum

PertanyaanJawaban
Apakah data siswa aman?Ya. Data tersimpan di Google Drive milik Bapak/Ibu sendiri dan hanya dapat dibuka oleh pemilik akun.
Kapan sebaiknya mengirim data?Setiap selesai memasukkan nilai atau absensi. Anggap seperti menekan tombol simpan.
Bisa dibuka dari HP?Bisa. Buka Dashboard di HP, tempel URL yang sama, lalu tekan Ambil dari Google Sheets.
Kalau internet mati?Dashboard tetap berjalan normal secara luring. Kirim data setelah internet tersedia kembali.
Apakah data lama tertimpa?Ya. Pengiriman terakhir akan menggantikan data sebelumnya di spreadsheet.
