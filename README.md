# Media Pembelajaran Bahasa Inggris Kelas IX
### SMP Negeri 1 Bangsal — Kabupaten Mojokerto, Jawa Timur

Media pembelajaran interaktif berbasis web untuk mata pelajaran **Bahasa Inggris Kelas IX**
mengacu pada buku **English for Nusantara** (Kurikulum Merdeka, Kemendikbudristek).

---

## 📚 Daftar Materi — Semester 1 (Ganjil)

| Chapter | Judul | Jenis Teks | Grammar Utama |
|---|---|---|---|
| 1 | Exploring Fauna of Indonesia | Descriptive / Report | Adjectives, possessive (its), has/have, passive voice |
| 2 | Taking Trips | Recount | Simple past, past continuous, when & while |
| 3 | Journeys to the Fantasy Worlds | Narrative | Direct & indirect speech, adverbs of manner |

Dilengkapi **PAS Semester 1** berisi 30 soal (Chapter 1–3) dengan timer 45 menit
dan analisis hasil per chapter.

---

## ✨ Fitur

- 🔊 **Text-to-speech** Bahasa Inggris untuk latihan listening & pronunciation
- 🖼️ **Ilustrasi** yang dapat diperbesar (cocok untuk proyektor / IFP)
- 🎮 **Permainan interaktif**: drag & drop, mencocokkan kata, menyusun cerita
- ✅ **Koreksi otomatis** disertai pembahasan setiap soal
- ⭐ **Sistem poin** dan progress bar belajar
- ✍️ **Writing task** dengan word bank, penghitung kata, dan tombol unduh
- 🖨️ **Cetak hasil** kuis dan PAS
- 📱 **Responsif** — dapat dibuka di komputer, IFP, maupun HP siswa
- 🔌 **Offline** — tidak memerlukan internet setelah halaman terbuka

---

## 🚀 Cara Membuka

**Online:** buka alamat GitHub Pages repository ini.

**Offline:** unduh seluruh file, simpan dalam **satu folder yang sama**,
lalu buka `index.html` menggunakan Google Chrome atau Microsoft Edge.

> ⚠️ Seluruh file harus berada dalam satu folder agar tautan antar halaman berfungsi.

---

## 📂 Struktur File

```
index.html              → Halaman menu utama
chapter1-fauna.html     → Chapter 1: Exploring Fauna of Indonesia
chapter2-trips.html     → Chapter 2: Taking Trips
chapter3-fantasy.html   → Chapter 3: Fantasy Worlds + PAS Semester 1
antrian-tu.html         → Aplikasi Antrian Ruang Tata Usaha
panduan-ifp.html        → Panduan membuka media di layar IFP
```

---

## 📝 Catatan

- Fitur suara memerlukan browser modern (Chrome/Edge) dengan paket suara Bahasa Inggris.
- Nilai kuis tersimpan pada perangkat yang digunakan. Gunakan tombol **Cetak** atau
  **Unduh** untuk mengumpulkan hasil pekerjaan siswa.
- Sumber materi: *English for Nusantara untuk SMP/MTs Kelas IX*, Pusat Perbukuan
  Kemendikbudristek, 2022.
